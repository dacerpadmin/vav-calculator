How it works. Area A = π/4·d² (round) or A = W·H (square). Velocity v = V̇/A with airflow V̇ converted to m³/s (CFM ×0.00047195, L/s ×0.001, m³/h ÷3600). Velocity pressure Pv = ½·ρ·v², ρ = 1.2 kg/m³. In the calibration tool the spigot's amplification factor is k = ΔP@V̇nom ÷ Pv(V̇nom), and the predicted ΔP = k·Pv(V̇). Because ΔP scales with the square of airflow, this equals ΔP@V̇nom · (V̇/V̇nom)². Pressure is also shown in mm water column (1 Pa ≈ 0.10197 mmWC).

Use the k value from your VAV box datasheet where you have it; the calibration tool recovers the same k from a single measured or quoted ΔP/airflow point. The re-span tool computes the ΔP the controller reads at the shown flow from the factory curve — ΔP = ΔP@V̇nom·(F1/V̇nom)² — then matches the reading to a third-party measurement. It raises V̇nom first (needed value V̇nom1·F2/F1), capped at 3.5·V̇max; if the cap still can't reach the target it pins V̇nom there and reduces ΔP@V̇nom so the controller reads F2 at that same ΔP (flow varies as √(ΔP/ΔP@V̇nom)).
