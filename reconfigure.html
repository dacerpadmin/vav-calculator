How it works. The controller reads flow as F = V̇nom·√(ΔP/ΔP@V̇nom). To make it read the third-party flow F2 at the same operating point, V̇nom is raised first (V̇nom·F2/F1), capped at 3.5·V̇max; if the cap isn't enough, ΔP@V̇nom is then reduced so it reads F2 (flow ∝ √ΔP). ΔP values are whole Pascals.
